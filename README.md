# OAG Services & Traders Website

A responsive static company website built with HTML, CSS and JavaScript.

## Files
- `index.html` — website structure/content
- `style.css` — responsive design
- `script.js` — mobile menu, animations and active navigation
- `assets/` — optional folder for your own logo/product images

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide the live website URL.

Replace the placeholder product visuals with real product photos by adding images to `assets/` and changing the corresponding CSS/HTML backgrounds.
